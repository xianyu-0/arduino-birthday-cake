# Arduino 智能生日蛋糕

基于 Arduino 的互动生日装置，实现吹气检测、LED 烛光、蜂鸣器播放生日歌。

## 功能
- 按键/吹气触发灯光效果
- 蜂鸣器播放生日快乐歌
- 串口打印调试信息

## 硬件
- Arduino UNO
- 声音传感器 / 火焰传感器
- LED、蜂鸣器

## 使用
1. 按接线图连接硬件
2. 用 Arduino IDE 打开 .ino 文件
3. 上传到开发板
